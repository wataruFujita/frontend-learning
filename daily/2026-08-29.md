## 条件付きレンダリング

- `v-if` … 条件によって要素を表示する
- `v-else` … `v-if` の条件が `false` の場合に表示する
- `v-else-if` … `v-if` の else if の条件にマッチした場合に表示する

`v-else` や `v-else-if` は、`v-if` の直後に定義する必要がある。

## `<template>` タグ

`<template>` は、トップレベルの `<template>` 以外でもタグとして使用できる。

```vue
<template>
  <button @click="ok = !ok">toggle</button>
  <template v-if="ok">
    <p>OK!</p>
    <p>OK!</p>
    <p>OK!</p>
    <p>OK!</p>
  </template>
</template>
```

この場合、ブラウザの DOM には `<template>` タグは表示されず、`<p>` タグが表示される。

## `v-show`

`v-if` と同様、値の真偽によって要素を表示する。

`v-show` には、`v-if` のような `v-else` や `v-else-if` は使用できない。

```vue
<template>
  <button @click="show = !show">toggle</button>
  <p v-show="show">Hello</p>
</template>
```

### `v-if` と `v-show` の違い

- `v-if` … 条件が `false` のとき、DOM から要素が完全に削除される
- `v-show` … 初期コストが高い（最初からすべての要素を DOM に作るため）

切り替えの頻度が低いときは `v-if`、頻度が高いときは `v-show` を使う。

## `v-for`

繰り返し処理を行う。記法は「エイリアス in 式」。

```vue
<div v-for="item in items">
  {{ item.text }}
</div>
```

## `key` 属性

`v-for` で要素とデータとを関連付けるために使用する。`key` には一意の値を指定する必要がある。

```vue
<div v-for="item in items" :key="item.id">
  {{ item.text }}
</div>
```

`key` 属性を使用しないと、意図しない要素の再利用が起きることがある。
