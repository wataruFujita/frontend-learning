## テキスト補間 `{{ }}`

テンプレート内では `{{ }}` で値を表示できる。

- 足し算・引き算などの計算ができる
- 三項演算子も使える

```vue
<template>
  <p>{{ count + 1 }}</p>
  <p>{{ isActive ? '有効' : '無効' }}</p>
</template>
```

## ディレクティブ

Vue には `v-` から始まる構文があり、これを **ディレクティブ** と呼ぶ。

```vue
<div v-text="count"></div>
```

例:

- `v-text` … 要素のテキストとして表示する
- `v-html` … HTML として挿入する
- `v-bind` … 属性に値を動的に設定する

### `v-bind`

```vue
<script setup>
import { ref } from 'vue'

const vueURL = ref('https://vuejs.org')
</script>

<template>
  <a v-bind:href="vueURL">Vue.js</a>
</template>
```

`v-bind:` は省略して `:` と書ける。

```vue
<a :href="vueURL">Vue.js</a>
```
