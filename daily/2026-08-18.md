### Vite

Vite は、Vue.js などのフロントエンドプロジェクトで利用できるビルドツールです。

主に以下の機能を提供します。

- 開発用サーバー
- 高速な HMR（Hot Module Replacement）
- 本番用ファイルのビルド
- プロジェクトの初期構成

公式のコマンドを使って、Vite プロジェクトを作成できます。

```bash
npm create vite@latest
```

Vue を指定して作成する場合は、次のように実行します。

```bash
npm create vite@latest my-vue-app -- --template vue
cd my-vue-app
npm install
npm run dev
```

Vite は「Vue 専用のツール」ではなく、React や Svelte などにも対応しています。
Vue プロジェクトでは、Vite と Vue の公式プラグインを組み合わせて利用します。

## Vue の単一ファイルコンポーネント

Vue では、`.vue` 拡張子のファイルに、コンポーネントのテンプレート・ロジック・スタイルをまとめて記述できます。

この形式を **Single-File Component（SFC）** と呼びます。

```vue
<script setup>
const message = 'Hello Vue!'
</script>

<template>
  <h1>{{ message }}</h1>
</template>

<style scoped>
h1 {
  color: blue;
}
</style>
```

基本的には次の3種類のブロックを使用します。

| ブロック | 役割 |
| --- | --- |
| `<template>` | 画面に表示するHTMLを記述する |
| `<script>` | JavaScriptやコンポーネントのロジックを記述する |
| `<style>` | CSSを記述する |

ただし、3つすべてが必須というわけではありません。たとえば、スタイルが不要なコンポーネントでは `<style>` を省略できます。

`<script setup>` を使用すると、スクリプト内で定義した変数や関数を、テンプレートから直接利用できます。

- [Vue 公式 Single-File Components](https://vuejs.org/guide/scaling-up/sfc.html)
