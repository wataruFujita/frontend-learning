## 学習内容

## `v-for` で index を取得する

```vue
<template>
  <div v-for="(item, index) in items" :key="item.id">
    {{ index }}
  </div>
</template>
```

`:key` にインデックスを使うと、配列の並び替えや削除を行った際に、表示の不具合や予期せぬバグの原因になることがある。

要素が一意の `id` を持っている場合は、可能な限り `id` を `:key` に指定する。

## `v-for` での分割代入

```vue
<template>
  <div v-for="({ name, age }, index) in items" :key="index">
    {{ name }} {{ age }}
  </div>
</template>
```

この場合、`name` と `age` に分割代入される。

## `<template>` と `v-for`

`v-for` は `<template>` タグと一緒に使用できる。不要なタグを増やしたくないときなどに利用できる。

```vue
<template v-for="item in items" :key="item.id">
  <div>
    {{ item.name }}
  </div>
</template>
```

## `v-for` と `v-if` を一緒に使う場合

`v-if` は `v-for` より先に評価される。

`v-if` と `v-for` を同じ要素内で使うことは推奨されていない。要素を分けて使う。

```vue
<template v-for="item in items" :key="item.id">
  <template v-if="item.isActive">
    {{ item.name }}
  </template>
</template>
```
