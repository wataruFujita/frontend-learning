## 要素の入れ子
- 要素の中に別の要素を入れられる（ネスト）
- **内側のタグを先に閉じ、その後に外側を閉じる**（交差させない）
  ```html
<!-- ○ 正しい -->
<p>うちの猫は<strong>とても</strong>不機嫌です。</p>
<!-- × 誤り（タグが交差している） -->
<p>うちの猫は<strong>とても不機嫌です。</p></strong>
```

## 空要素
- 単一タグ、終了タグを必要としない
- 文書内のその位置に、何か（改行・画像など）を挿入する用途が多い
- 例：<br>

## 属性
- 要素に追加情報を含ませるために使用
- 例：<img>
  - src … 画像の URL（必須）
  - alt … 画像の説明（見えない人向け）
  - width / height … 表示サイズ（px） 

<img
  src="https://example.com/image.png"
  alt="画像の説明"
  width="300" />

## 論理属性
- 値の設定が不要な属性（書かれているだけで有効）
- 値の有無・内容に関わらず `true` として扱われる
- 例: `disabled`
```html
<input type="text" disabled />
```

## 属性の引用符
- 引用符は省略できる場合もあるが、常に付けるのがおすすめ
- 値に空白があるのに省略すると、複数の属性として解釈されてしまう
- 二重引用符 " と単一引用符 ' はどちらでもよい
- **開始と終了で混在させるとエラー**になる（"..."' など）

## HTML 文書の基礎構造
```html
<!doctype html>
<html lang="ja">
  <head>
    <meta charset="utf-8" />
    <title>ページのタイトル</title>
  </head>
  <body>
    <!-- 表示されるコンテンツ -->
  </body>
</html>
```
- `<!doctype html>`：文書型宣言（ページ先頭に書く）
- `<html>`：ページ全体を囲むルート要素  
- `<head>`：ページ情報（表示されない）の入れ物  
- `<meta charset="utf-8">`：文字コードの指定  
- `<title>`：タブやブックマークに出るタイトル 
- `<body>`：画面に表示されるコンテンツ 

## 文字参照（特殊文字）
テキストに < > " ' & をそのまま書くと HTML 構文と衝突するので、文字参照に置き換える。
