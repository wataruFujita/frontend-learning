## テンプレートと JavaScript の組み合わせ

Vue のテンプレートは、HTMLをベースにしたテンプレート構文で記述します。

テンプレート内では、`{{ }}` を使って JavaScript の値を表示できます。この記法を **テキスト補間**、または **Mustache構文** と呼びます。

```vue
<script setup>
const hello = 'Hello Vue!'
const number = 10
</script>

<template>
  <p>{{ hello }}</p>
  <p>{{ number + 1 }}</p>
</template>
```

`{{ }}` の中には、単純な変数だけでなく、JavaScriptの式も記述できます。

```vue
<script setup>
const isActive = true
const message = 'hello'
</script>

<template>
  <p>{{ isActive ? '有効' : '無効' }}</p>
  <p>{{ message.toUpperCase() }}</p>
</template>
```

ただし、`{{ }}` の中に `if` 文や `for` 文などの文（statement）を記述することはできません。基本的には、値を返す式を記述します。

Vue のテンプレートはHTMLをそのままJavaScriptとして読むのではなく、VueによってJavaScriptの描画処理へコンパイルされます。

## クリック時に処理を実行する

Vue では、`v-on` ディレクティブを使ってイベントを監視できます。

```vue
<button v-on:click="increment">+1</button>
```

`v-on:click` は、`@click` と短く記述できます。

```vue
<script setup>
import { ref } from 'vue'

const count = ref(0)

function increment() {
  count.value++
}
</script>

<template>
  <p>現在の値：{{ count }}</p>
  <button @click="increment">+1</button>
</template>
```

`@click="increment"` のように関数名だけを指定すると、クリック時にその関数が実行されます。

簡単な処理であれば、テンプレート内に直接記述することもできます。

```vue
<script setup>
import { ref } from 'vue'

const count = ref(0)
</script>

<template>
  <button @click="count++">
    {{ count }}
  </button>
</template>
```

関数に引数を渡す場合は、関数呼び出しの形式にします。

```vue
<script setup>
function say(message) {
  alert(message)
}
</script>

<template>
  <button @click="say('こんにちは')">実行</button>
</template>
```

## リアクティビティ

Vue のリアクティビティとは、データの変更を検知し、それに応じて画面を自動的に更新する仕組みです。

### `ref()`

Composition API では、リアクティブな状態を定義するために `ref()` を使うことが推奨されています。

`ref()` は、文字列・数値・真偽値などのプリミティブ値にも使用できます。

```vue
<script setup>
import { ref } from 'vue'

const name = ref('Vue')
const count = ref(0)
const isVisible = ref(true)
</script>
```

JavaScriptの中で値を読み書きするときは `.value` を使用します。

```js
const count = ref(0)

console.log(count.value)

count.value++
```

一方、テンプレート内では、トップレベルにある `ref` は自動的にアンラップされるため、`.value` を記述する必要はありません。

```vue
<template>
  <p>{{ count }}</p>
  <button @click="count++">+1</button>
</template>
```

`ref()` はプリミティブ値だけでなく、オブジェクトや配列にも使用できます。オブジェクトを `ref()` に渡した場合、オブジェクトの内部も深くリアクティブになります。

```js
const user = ref({
  name: 'Yoshipi',
  profile: {
    age: 25
  }
})

user.value.profile.age++
```

### `reactive()`

`reactive()` は、オブジェクトそのものをリアクティブな Proxy に変換します。

```js
import { reactive } from 'vue'

const state = reactive({
  count: 0,
  user: {
    name: 'Yoshipi'
  }
})

state.count++
state.user.name = 'Vue User'
```

`reactive()` は、オブジェクト・配列・`Map`・`Set` などに使用できますが、文字列や数値などのプリミティブ値には使用できません。

`reactive()` で作成したオブジェクトの中にあるネストされたオブジェクトも、基本的には深くリアクティブになります。

```js
const instructor = reactive({
  name: 'Yoshipi',
  age: 25,
  sns: {
    twitter: 'hoge',
    youtube: 'hoge'
  }
})

instructor.sns.twitter = 'new account'
```

`reactive()` には、次のような制限があります。

- プリミティブ値を直接扱えない
- リアクティブオブジェクト全体を別のオブジェクトに置き換えるのが難しい
- 分割代入するとリアクティビティを失いやすい

そのため、Vue公式ドキュメントでは、リアクティブな状態を宣言する主要なAPIとして `ref()` の使用が推奨されています。

### 参考

- [Vue 公式 Reactivity Fundamentals](https://vuejs.org/guide/essentials/reactivity-fundamentals)
- [Vue 公式 Reactivity API: Core](https://vuejs.org/api/reactivity-core.html)

## `reactive()` 内に `ref()` を入れた場合

`reactive()` のオブジェクトのプロパティに `ref()` を設定すると、そのプロパティを参照するときに `.value` が自動的に省略されます。

```js
import { reactive, ref } from 'vue'

const instructor = reactive({
  name: ref('Yoshipi'),
  age: 25,
  sns: {
    twitter: ref('hoge'),
    youtube: 'hoge'
  }
})

console.log(instructor.name)
console.log(instructor.sns.twitter)
```

また、プロパティに値を代入すると、内部の `ref` の値が更新されます。

```js
instructor.name = 'New Name'

console.log(instructor.name) // New Name
```

ただし、この自動アンラップは、深いリアクティブオブジェクトのプロパティに対して行われるものです。

## リアクティブ配列内の `ref`

リアクティブな配列の要素として `ref` を格納した場合、配列要素では自動アンラップされません。

```js
import { reactive, ref } from 'vue'

const books = reactive([
  ref('Vue 3 Guide')
])

console.log(books[0].value)
```

この場合、`books[0]` は文字列ではなく `ref` オブジェクトです。文字列の値を取得するには `.value` が必要です。

```js
console.log(books[0])       // Refオブジェクト
console.log(books[0].value) // Vue 3 Guide
```

これは、`reactive()` の通常のオブジェクトプロパティとは異なる点です。

## テンプレート内での `ref` の自動アンラップ

テンプレートでは、トップレベルに定義された `ref` は自動的にアンラップされます。

```vue
<script setup>
import { ref } from 'vue'

const count = ref(0)
</script>

<template>
  <p>{{ count }}</p>
</template>
```

しかし、通常のオブジェクトの内部にある `ref` は、自動アンラップされません。

```vue
<script setup>
import { ref } from 'vue'

const object = {
  id: ref(1)
}
</script>

<template>
  <p>{{ object.id.value }}</p>
</template>
```

次のように書くと、`object.id` は `ref` オブジェクトのまま扱われます。

```vue
<template>
  <!-- object.id は自動アンラップされない -->
  <p>{{ object.id + 1 }}</p>
</template>
```

`ref` をトップレベルの変数として扱えば、自動アンラップされます。

```vue
<script setup>
import { ref } from 'vue'

const object = {
  id: ref(1)
}

const { id } = object
</script>

<template>
  <p>{{ id + 1 }}</p>
</template>
```

つまり、テンプレートの自動アンラップは「最初のオブジェクトがリアクティブかどうか」だけで決まるのではなく、テンプレートの描画コンテキストにおけるトップレベルの `ref` かどうかが重要です。

## 要点まとめ

- `.vue` ファイルは Vue の単一ファイルコンポーネントである
- `<template>`、`<script>`、`<style>` を同じファイルに記述できる
- `{{ }}` でデータを表示できる
- `{{ }}` の中には JavaScript の式を記述できる
- `@click` はクリックイベントを処理するための `v-on:click` の短縮記法
- `ref()` はプリミティブ値にもオブジェクトにも使用できる
- JavaScript内では `ref` の値に `.value` でアクセスする
- テンプレート内のトップレベルの `ref` は `.value` を省略できる
- `reactive()` はオブジェクトをリアクティブな Proxy に変換する
- `reactive()` 内の通常のプロパティでは、ネストされた `ref` も自動アンラップされる
- リアクティブ配列の要素に入れた `ref` は自動アンラップされない
- 通常のオブジェクト内部の `ref` は、テンプレート内でも自動アンラップされない
- Composition API では、一般的に `ref()` が主要なリアクティブ状態の宣言方法として推奨される
