## Emmet（VS Code の補完）
よく使う書き方：

| 操作 | 入力 | 展開結果 |
|------|------|----------|
| クラス付与 (`.`) | `div.container` | `<div class="container"></div>` |
| ID付与 (`#`) | `h1#title` | `<h1 id="title"></h1>` |
| タグ名省略（自動で `div`） | `.card` | `<div class="card"></div>` |
| 子要素 (`>`) | `ul>li` | `<ul><li></li></ul>` |
| 複数作成 (`*`) | `li*3` | `<li></li>` が3つ |
| テキスト (`{}`) | `button.btn{送信}` | `<button class="btn">送信</button>` |

## CSS の読み込み
```html
<link rel="stylesheet" href="style.css">
```
HTML に外部 CSS を読み込む記述。
- `<link>`：外部リソースと HTML 文書を関連付けるタグ
- `rel="stylesheet"`：読み込むファイルがスタイルシートであることを示す（relation の略）
- `href="style.css"`：読み込む CSS のパスを指定（hypertext reference の略）

## Sass
参考：[Sass ガイド](https://sass-lang.com/guide/)

### メリット
- ネストで書ける
- 変数を使える

### コンパイル
- ブラウザは `.css` しか理解できない
- `.scss` は `.css` に変換（コンパイル）してから HTML で読み込む
- 拡張機能 Live Sass Compiler でコンパイル可能

### コンパイルできない場合の原因例
- Sass ファイル内の記述が間違っている
