## 学習内容

`computed` 以外に、値の変更を検知して処理を実行する関数として `watch` と `watchEffect` がある。

## `watchEffect`

`watchEffect` 内部で、監視したい変数の読み取りがないと自動検知は行われない。

これは `count.value` の読み取りがある。

```js
watchEffect(() => {
  console.log('watchEffect')
  console.log(count.value)
  count.value = 'hello'
})
```

これは読み取りを行わない。

```js
watchEffect(() => {
  console.log('watchEffect')
  count.value = 'hello'
})
```

## `watch`

引数を2つ取る。

- 第1引数 … 監視したいリアクティブな値
- 第2引数 … 監視している値が変化したときに実行する関数

```js
watch(count, () => {
  console.log(count.value)
})
```

`watchEffect` との違いは、監視したい値を明示的に指定する点。

第2引数の関数には引数を2つ渡せる。

- 第1引数 … 監視している値の最新の値
- 第2引数 … 監視している値の前の値

```js
watch(count, (newVal, oldVal) => {
  console.log(newVal)
  console.log(oldVal)
})
```

### 注意点

第1引数にはリアクティブなオブジェクトを指定する。実際の値（`value.value`）は指定しない。

```js
watch(value, () => {
  console.log(value)
})
```

これは NG。

```js
watch(value.value, () => {
  console.log(value)
})
```

第1引数には関数を指定することもできる。

```js
watch(() => value.value, () => {
  console.log(value)
})
```

第1引数に配列を渡し、複数の値を監視することもできる。

```js
watch([count, value], () => {
  console.log(count.value)
  console.log(value.value)
})
```

リアクティブオブジェクトのプロパティを監視する場合、値を直接引数に指定するのではなく、関数で指定する必要がある。

```js
const value = ref({
  name: 'John',
  age: 30
})

// age を監視したい場合
watch(() => value.value.age, () => {
  console.log(value)
})
```

第3引数にはオプションを指定できる。

```js
watch(count, () => {
  console.log(count.value)
}, {
  immediate: true
})
```
