## 学習内容

## `v-for` でオブジェクトを取得する

```vue
<template>
  <div v-for="value in object" :key="value">
    {{ value }}
  </div>
</template>
```

2つ目の引数にはキーを、3つ目の引数にはインデックスを指定して取得できる。

```vue
<template>
  <div v-for="(value, key, index) in object" :key="index">
    {{ key }} {{ value }}
  </div>
</template>
```

## 指定した数値だけ繰り返す

```vue
<template>
  <div v-for="i in 10" :key="i">
    {{ i }}
  </div>
</template>
```

`in` の代わりに `of` を使うこともできる。

```vue
<template>
  <div v-for="i of 10" :key="i">
    {{ i }}
  </div>
</template>
```
