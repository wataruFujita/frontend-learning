## JavaScript について
- ブラウザで動く言語
- サーバー上でも実行可能

`<script>` タグで HTML 文書の任意の場所に挿入できる。

例:
```html
<!DOCTYPE HTML>
<html>
<body>
  <p>Before the script...</p>

  <script>
    alert('Hello, world!');
  </script>

  <p>...After the script.</p>
</body>
</html>
```

`src` 属性でファイルパスを指定し、別ファイルの JavaScript を読み込める。

例:
```html
<script src="/path/to/script.js"></script>
```

- `src` が設定されている場合、`<script>` タグ内の中身は無視される
- 1つの `<script>` タグで `src` と中身のコードを両方持つことはできない

## セミコロン
文はセミコロンで区切る。

```js
alert('Hello');
alert('World');
```

- セミコロンは省略可能
- 改行すると内部的にセミコロンが自動挿入される場合もある
- ただし `[...]` のように、前方にセミコロンが自動挿入されない場合もある

## コメント
1行コメントは `//` から始める。

```js
// コメント
```

複数行は `/*` と `*/` で囲む。

## `"use strict"` について
スクリプトの先頭に記載することで、厳格モードを有効にできる。

```js
"use strict";
```

## 変数
変数の定義には `let` キーワードを使う（`var` でも可）。

```js
let message;
```

- 複数の単語を含む名前はキャメルケースが一般的
- 大文字小文字は区別される
- 予約語を変数名に使うことはできない
- 定数は `const` を使う
- JavaScript は動的型付け言語

## 関数
基本形:

```js
function name(parameters) {
  // ...body...
}
```

- 同ファイル内の外部変数にもアクセスできる
- 外部変数の変更も可能

例:
```js
let userName = 'John';

function showMessage() {
  let message = 'Hello, ' + userName;
  alert(message);
}
```

引数が2つの関数でも、1つだけ渡して呼び出せる。

```js
showMessage("Ann");
```

この場合、渡されなかった `text` は `undefined` になる。

デフォルト値を設定することもできる。

```js
function showMessage(from, text = "no text given") {
  alert(from + ": " + text);
}

showMessage("Ann"); // Ann: no text given
```

`text` が渡されていない場合、値は `"no text given"` になる。
