## 学習内容

## `v-bind` で複数属性をまとめて設定する

オブジェクトを渡すと、一度に複数の属性を設定できる。

```vue
<a v-bind="{ id: vueId, href: vueURL }">Vue.js</a>
```

## `v-on`

指定したイベント発生時に、特定の処理を実行する。

例: クリックしたときに値を増やす。

```vue
<script setup>
import { ref } from 'vue'

const count = ref(0)
</script>

<template>
  <button v-on:click="count++">button</button>
</template>
```

`v-on:click` は `@click` と書き換えられる。

```vue
<button @click="count++">button</button>
```

## イベントオブジェクト

ブラウザはイベント発生時に、イベントオブジェクトを自動生成する。

インラインハンドラーでは `$event` という名前で参照できる。

### ハンドラに引数を渡す

```vue
<button @click="countUp($event, 5)">button</button>
```

### `preventDefault`

イベントオブジェクトはメソッドを持つ。`preventDefault` はデフォルトの動作をキャンセルする。

```vue
<a href="https://vuejs.org" @click="$event.preventDefault()">Vue.js</a>
```

イベント修飾子でも同じことができる。

```vue
<a href="https://vuejs.org" @click.prevent>Vue.js</a>
```

## キー修飾子

キーボードイベントは `@keyup` などで扱う。

例: 入力のたびにカウントアップする。

```vue
<script setup>
import { ref } from 'vue'

const count = ref(0)
</script>

<template>
  <p>{{ count }}</p>
  <input type="text" @keyup="count++">
</template>
```

特定のキーだけ対象にすることもできる。

例: Enter キーを押したときにカウントアップする。

```vue
<input type="text" @keyup.enter="count++">
```

## ディレクティブの構造

```
v-名前:引数.修飾子="値"
```

| 部分 | 役割 | 例 |
|---|---|---|
| 接頭辞 `v-` | Vue の機能であることを示す | `v-on` |
| 名前 | ディレクティブ名 | `bind` / `on` |
| 引数 `:` | どの部分に作用させるか | `v-bind:href` の `href` |
| 修飾子 `.` | 動作を追加で変える | `v-on:click.prevent` |
| 値 `=" "` | JavaScript の式やデータ | `"save"` |

例: 送信時のデフォルト動作を止める。

```vue
<form v-on:submit.prevent="save">
```

### 引数をスクリプトのデータで指定する

動的な引数は角括弧 `[]` で書く。

```vue
<script setup>
import { ref } from 'vue'

const attributeName = 'href'
</script>

<template>
  <div v-bind:[attributeName]="value"></div>
</template>
```

## `v-model`

入力値をスクリプト側の変数と同期するには `v-model` を使う。

```vue
<script setup>
import { ref } from 'vue'

const inputValue = ref('')
</script>

<template>
  <input type="text" v-model="inputValue">
</template>
```

## `computed`

他のデータをもとに計算した結果を自動でキャッシュし、元データが変わったときだけ再計算する機能。
