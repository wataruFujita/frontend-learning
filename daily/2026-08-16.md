## 関数式

変数に代入する形で関数を定義できる。

```js
let sayHi = function() {
  alert("Hello");
};
```

関数を別の変数にコピーすることも可能。

### 関数式と関数宣言の違い

- **関数式** … 実行がその定義に到達したときに作られ、それ以降で利用可能になる
- **関数宣言** … 実行がその定義に到達する前でも利用可能（ブロック内ならどこからでも参照できる）

関数宣言は、定義の前でも呼べる。

```js
sayHi("John"); // Hello, John

function sayHi(name) {
  alert(`Hello, ${name}`);
}
```

関数式は、定義の前に呼ぶとエラーになる。

```js
sayHi("John"); // エラー

let sayHi = function(name) {
  alert(`Hello, ${name}`);
};
```

定義前でも実行できるため、関数宣言を使う方が望ましい。

## コールバック関数

別の関数に引数として渡し、その関数の内部で実行される関数。

以下では `showOk` と `showCancel` がコールバックとして `ask` に渡される。

```js
function ask(question, yes, no) {
  if (confirm(question)) yes();
  else no();
}

function showOk() {
  alert("You agreed.");
}

function showCancel() {
  alert("You canceled the execution.");
}

ask("Do you agree?", showOk, showCancel);
```

## 無名関数

名前を持たない関数。

```js
function() {
  alert("Hello");
}
```

## アロー関数

関数式は、アロー関数に書き換えられる。

```js
let func = function(arg1, arg2, ...argN) {
  return expression;
};
```

```js
let func = (arg1, arg2, ...argN) => expression;
```

- 引数が1つの場合、括弧を省略できる
- 引数がない場合は、空の括弧が必要
- 波括弧を使うと、複数行の関数を書ける

```js
let double = n => n * 2;

let hello = () => alert("Hello!");

let sum = (a, b) => {
  let result = a + b;
  return result;
};
```

## 条件分岐

基本形:

```js
if (year == 2015) {
  alert("That's correct!");
  alert("You're so smart!");
}
```

数値 `0`、空文字 `""`、`null`、`undefined`、`NaN` は `false` になる。

```js
if (0) { // 0 は偽
  // ...
}
```

`else` 句:

```js
let year = 2015;

if (year == 2015) {
  alert("You guessed it right!");
} else {
  alert("How can you be so wrong?"); // 2015 以外のケース
}
```

三項演算子:

```js
let result = condition ? value1 : value2;
```

`condition` が真なら `value1`、そうでなければ `value2` が返る。

```js
let accessAllowed = (age > 18) ? true : false;
```
