## `v-bind` による class の動的な指定

class へのスタイル指定は、次のようにも書ける。

```html
<div class="red bg-blue">Hello</div>
```

真偽値を切り替えることで、適用したいクラスを切り替えられる。

```vue
<div :class="{ red: true, 'bg-blue': true }">Hello</div>
```

配列でも、動的にクラスを指定できる。

```vue
<script>
const red = 'red'
const blue = 'bg-blue'
</script>

<template>
  <div :class="[red, blue]">Hello</div>
</template>
```

静的な class と動的な class を組み合わせることもできる。

```vue
<script>
const red = 'red'
const blue = 'bg-blue'
</script>

<template>
  <div class="static-class" :class="[red, blue]">Hello</div>
</template>
```

## `v-bind` による style の動的な指定

style 属性も `v-bind` で動的に指定できる。

class 属性とは異なり、オブジェクトにプロパティと値のペアで指定する。

```vue
<div :style="{ color: 'red', fontSize: '16px' }">Hello</div>
```

プロパティはキャメルケース・ケバブケースのどちらも指定できるが、キャメルケースが推奨されている。

style 属性も、静的なスタイルと動的なスタイルを組み合わせることができる。
